These sources already contain native softened/noisy boundary colors in some cases. Extraction retains those RGB values; it does not sharpen, recolor, smooth or reconstruct them. Conservative ambiguous boundary pixels remain. Visual certification concerns the saved alpha boundary; automated checks prove source-coordinate/RGB integrity, not semantic ownership of every source pixel.

Manual preparation used source-specific connectivity/color-assisted proposals, bounded corrections, reviewed openings and protected details. Corvus and Firefly have traced block contours; Lemur has a separately reviewed dark-tail region. There is no largest-component selection rule (both Pisces fish and disconnected Ankylosaurus plate pixels remain). Production replay applies the saved mask only; no thresholds are recalculated. Changes to either source or mask require re-review.
