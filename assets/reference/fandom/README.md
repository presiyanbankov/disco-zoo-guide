# Reviewed Fandom references

All 30 supported classic animal PNG responses are retained byte-for-byte, separate from canonical production art. The first four reference records are below; the complete 30-file inventory and source URLs are in public/game/animals-hq/README.md.
Exact bytes and SHA-256 hashes are pinned in `scripts/fandomExtractionProfiles.json`; the original four also remain pinned in `scripts/extractFandomPrototype.py`.
Existing reference files are never overwritten by the script's download option.

## Approved Jungle and Moon sources

Twelve unchanged 150x150 reference PNGs were added for Monkey, Toucan, Gorilla, Panda, Tiger, Phoenix, Moonkey, Lunar Tick, Tribble, Moonicorn, Luna Moth and Jade Rabbit. Deterministic lowercase IDs match the canonical records. Source URLs and hashes are pinned in scripts/fandomExtractionProfiles.json; final dimensions and source-space masks/seeds are recorded in [the HQ inventory](../../../public/game/animals-hq/README.md). No resampling/recoloring of reference files occurred.
